### 应该使用哪个现有 skill

主 skill 用 **`hyperframes`** 就可以。

它适合这种任务，因为目标是：

> 用 HTML / SVG / CSS / JavaScript 做确定性的图表动画，再渲染成视频。

`hyperframes` 内部可以按需使用：

- `hyperframes-animation`：动画节奏、转场和 motion
- `hyperframes-keyframes`：时间点、缓动、路径运动
- `hyperframes-creative`：配色、字体、视觉层级
- `media-use`：图标、徽章、图片等素材

`visual-page` 只有在你希望先做一个可交互网页版本时才有价值；最终要输出 MP4，主路线仍然是 `hyperframes`。

### 不建议用哪种方式

不建议用 MiniMax H3、Hailuo 或其他文生视频模型来生成这个效果。

因为这类视频的关键不是“生成一段看起来像科技感的数据视频”，而是：

- 文字必须准确
- 曲线数据必须稳定
- 节点位置必须一致
- 徽章必须准确贴合曲线
- 动画可以精确到帧
- 后续可以换数据、换颜色、换文案

这些应该用代码动画完成，而不是让视频模型猜。

### 复刻难度

**视觉效果：可以高保真复刻。**

关键实现大致是：

1. 用 SVG 绘制坐标轴、网格和曲线；
2. 用 `stroke-dasharray` + `stroke-dashoffset` 做曲线生长；
3. 用 `path.getPointAtLength()` 计算曲线当前末端坐标；
4. 让徽章跟随末端移动；
5. 在指定进度触发残影、标签和脉冲效果；
6. 动画结束后切换到最终图表状态；
7. 由 `hyperframes` 渲染成 60fps MP4。

如果要接近原视频的像素级效果，需要匹配：

- 原始数据
- 画布比例和裁切范围
- 字体
- 颜色 token
- 曲线插值方式
- 每个标签出现的时间点
- 录屏时的缩放和抗锯齿

由于 HarnessTax 的页面源码和数据是公开的，复刻难度比单纯看一段视频低很多。
