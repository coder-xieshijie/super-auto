`raw/*.mp4` 是从 X 的 HLS 流保存的 720p 音视频副本；`raw/*.info.json` 是 `yt-dlp` 提取的帖子和媒体元数据。`raw/*.en.vtt` 是 X 提供的英文字幕原件。`transcripts/*.md` 是字幕逐条清除标记、每 30 秒合并成一段的完整英文文字稿；`transcripts/*.cues.tsv` 保留每条字幕的起止时间与文字。转换脚本在 `working/vtt_to_transcript.py`，未改写原文。字幕可能有错词、断句或漏词，故不能当作人工核对的逐字稿。两段视频未标记多说话人，58 分钟访谈中的主持人与 Lauren 发言需结合上下文识别。

`manifest.json` 记录两段 MP4 的 ffprobe 时长、音视频轨道，以及视频、字幕、元数据、文字稿各文件的大小和 SHA-256，便于后续复核副本完整性。
