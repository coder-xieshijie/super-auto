# 三路研究独立核查

审查日期：2026-09-28。审查对象为 architecture / industry / evidence 三份 `findings.md`，对应文件 SHA 见 [reviewed-inputs.json](reviewed-inputs.json)。本审查没有修改它们。审查开始时根报告尚未写入；本文件先覆盖材料间一致性，根报告审查另追加。

## 当前结论

没有发现需要阻止综合写作的事实冲突。材料已区分实验、自述与推导；企业数字未冒充本用户收益。不过根报告要保留下面五个边界，压缩时容易丢失。

1. **跨需求并发与需求内协作必须分别说明。** Scaling v3 是固定预算的协作架构比较，不是“多个独立工单各跑一个 worker”的吞吐实验。代码任务子集仅 20 题，不可用其相对下降否定跨需求并发。产业材料的仓库迁移、多个 UI screen、共享 fixture 验证三种场景已分别说明，不构成与实验矛盾。
2. **Cursor 删除 integrator 与工业候选版本验收可以同时成立。** Cursor 浏览器是研究项目，允许中间错误；根报告可以建议去掉万能协调角色，但仍要有人/机制拥有整合版本验收。不要写成“所有任务都需要中央 integrator”，也不要写成“取消集成验证才高吞吐”。
3. **持久需求身份不等于必须引入持久调度数据库。** Symphony 规范保留单一内存调度权威，并从 tracker / filesystem 恢复。Anthropic / Shopify durable session 的对象是会话事件。两者恢复边界不同，不能合并成一个所有系统共同证实的架构要求。
4. **受保护验收与可见开发反馈可以同时成立。** MirrorCode 提供可见样例与参照程序，另有隐藏测试；StrongDM 把场景独立保存。移植到工业项目应给 agent 足够反馈，把最终判定及场景来源保护起来，而不是不给任务必要上下文。
5. **企业收益自述不等于因果效果。** Stripe 的已合并 PR、Ramp 的采用份额、OpenAI 的前后 PR 增量、Shopify backlog 核销、Uber 的评论采纳率，分母与结果不同。不能汇总平均“提高多少倍”，或作为用户未来 throughput 承诺。

## 可修的措辞问题

### R1：architecture 的“删除 judge、集中 integrator”有歧义（低优先级）

原句可能被读作“删除 judge、集中设置 integrator”。原始 Cursor 文的 `Removing the integrator` 明确是取消集中 integrator（原始快照 A02 第 119–123 行）。建议根报告写“后来又移除了 judge 和集中 integrator 两个角色”。现有架构材料下一段已说明其限制，事实本身无误。

### R2：别把研究发布日期当数据时期（压缩报告时必须保留）

- METR 2025 实验是早 2025 工具；2026 更新认为后续信号受选择偏差影响。
- 2026-07 的 Early Adoption 论文实测窗口是 2025-05 至 07。
- MSR 2026 PR 协作研究使用 2025-11 取得的 AIDev v3。
- DORA 要区分 2024 负吞吐关联与 2025 正吞吐、仍有不稳定性的关联。
- 企业文章“Published Time”可能是再抓取/更新信息。industry 已对 Shopify 保存原站 HTML，Stripe 日期仅用 Exa 索引作为边界说明；根报告无需强行给后者精确日。

## 审查与维护成本的边界

企业自述能解释为什么需要 review 降噪；学术 PR 研究能描述可观察互动和 elapsed decision time。它们都不能直接证明每个 agent PR 平均消耗多少人工分钟，或其长期维护成本更低。根报告应保留该缺口，把人工分钟、合并后返工、缺陷逃逸作为本地试验采集项。

### R3：试验方案的 docs-only 修饰范围应与用户原规则一致

建议改为：“所有 docs-only MR 继续走用户既定短路径：完成必要文档检查、commit/push 和 MR 创建/更新后结束，不主动查询或等待 CI；不将其纳入复杂需求流程实验。”

位置：`experiments.md:36–42`，阶段二同时改变 owner 持续性、验收前移、反馈接续。可以用于比较整套流程是否值得用，但不能单独断言收益来自连续 owner。标题“试连续 owner”略窄于实际干预。

建议补一句：“此阶段评价三项组合的净效果，不能拆分各项贡献；要决定保留哪个组件，在阶段四逐项消融。”现文已经避免统计显著和提速承诺，因此这属于解释边界补强，不阻止实施。
