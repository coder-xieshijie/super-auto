# 独立审核后的收敛

日期：2026-09-28。两个审查者分别核对证据与架构，原记录保留；根作者根据意见修改以下项目。

| 发现 | 处理 |
|---|---|
| docs-only 限定“低影响”会缩窄用户规则 | experiments 改为所有 docs-only MR 的既定短路径，不主动查询/等待 CI |
| 阶段二同时改变三个机制，可能误归因 | 改名“连续交付组合”，明确只能判断组合净效果，最终质量门槛保持一致 |
| 上游就绪可能被理解为必须先合入 | 明确开发与合入依赖：已验证 feature SHA 可开发；保留 Archon/IDL 现有顺序 |
| 连续 owner 可能被理解为永不更换 session | 明确责任/状态连续，可以替换执行者；接续前核对旧执行停止或失去写权 |
| 小样本 p90 与事后阈值 | 先展示逐项时间与样本量；开始前记录预算、停止与扩容观察窗口 |
| 新访谈原仅有公开摘要 | 公开浏览器字幕导出成功后更新 REQUEST/Lauren/根报告；专人完整读取并核对 20 个时间戳，避免误归属 |

新增访谈自动字幕未人工听校，也没有视觉验证。两路初次 review 的 SHA 对应当时版本，不冒称已覆盖所有后续修改；本文件记录收敛，最终文件/来源完整性另见 validation.json。
