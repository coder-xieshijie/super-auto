1. Rust is a systems programming language designed for safety, speed, and concurrency.
2. It first appeared publicly in 2010 and reached its 1.0 stable release in May 2015.
3. Rust's ownership system gives every value a single owner, preventing data races at compile time.
4. Borrowing rules let values be referenced immutably or mutably, but never both at the same time.
5. Lifetimes are the compiler's mechanism for checking how long references remain valid.
6. The language has no garbage collector and does not require a runtime, so performance is predictable.
7. Cargo is Rust's official build tool and package manager, and it handles dependencies and testing.
8. Rust code compiles to native machine code through LLVM, with no garbage-collected runtime required.
9. Cargo, rustc, and the standard library are all written mostly in Rust itself, including the compiler.
10. Rust is used in production by companies such as Microsoft, Google, Amazon, Meta, and Cloudflare.
