1. Rust is a systems programming language focused on safety, speed, and concurrency.
2. It was first publicly released in 2015 and reached its 1.0 version on May 9, 2015.
3. Ownership and borrowing rules let the compiler prevent data races and use-after-free at compile time.
4. Its mascot is Ferris the crab, introduced as an alternative to the original "Boo" mascot.
5. Rust has no garbage collector; memory is managed through ownership, borrowing, and explicit freeing.
6. Cargo is Rust's official build system and package manager, handling dependencies, builds, and tests.
7. The compiler uses LLVM as its backend for generating optimized machine code.
8. Rust's type system is statically typed, with type inference and traits for polymorphism.
9. Null references are rejected by the compiler; optional values use the Option type instead.
10. Rust powers systems software and browsers, including Firefox components, Servo, and Windows' new memory-safe code.
